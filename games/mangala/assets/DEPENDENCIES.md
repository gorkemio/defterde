# Yerel bağımlılıklar

Uygulama dış ağ isteği yapmaz. Dosyalar güncel `defterde/games/dokuztas`
kopyasından, Marck Script ise `defterde/games/xox` kopyasından alındı.
Tam kaynak yolları ve SHA-256 özetleri `sources.json` dosyasındadır.

| Varlık | Sürüm / kaynak | Lisans |
|---|---|---|
| rough-4.6.6.js | Rough.js 4.6.6 UMD | MIT; vendor/rough-LICENSE |
| Kalam-Regular.ttf | Kalam 2.001; google/fonts ofl/kalam | SIL OFL; fonts/Kalam-OFL.txt |
| PatrickHand-v25.ttf | Patrick Hand v25 | SIL OFL; fonts/PatrickHand-OFL.txt |
| MarckScript-Regular.ttf | google/fonts ofl/marckscript | SIL OFL; fonts/MarckScript-OFL.txt |
| kit/gren.png | Defterde ortak yerel kağıt greni | Mevcut proje varlığı; aynen kopyalandı |

Kit'in malzeme dosyaları aynen kopyalandı; Mangala uyarlamaları style.css ve
draw.js içindedir. Referans görsel uygulamaya yüklenmez, yalnız docs içindeki
karşılaştırma sayfasında kullanılır. Aslı kullanıcının referans.png dosyasıdır.
